~/projects

research/firmware-pipeline

Firmware vulnerability pipeline

Offline pipeline for ARES that takes firmware images through static analysis, QEMU emulation and local-LLM triage, with a human-approved reporting gate to keep false positives out.

Python · QEMU · local LLMs

homelab/minecraft-wazuh

Home lab: dashboard + Wazuh SIEM

Flask dashboard for a Dockerized Minecraft server, kept on localhost behind hashed-password auth and rate limiting. Custom Wazuh decoders and rules alert on brute-force logins, non-whitelisted joins and crashes, each verified by triggering it live.

Python · Flask · Docker · Wazuh

Flying Broom flight controller

A flying broomstick built by a team of three at UGAHacks 11. I wrote the flight control software on two ESP32s, sending joystick input peer to peer in real time.

C · ESP32 · embedded
